# BioDeathrest

RimWorld 1.6.4850 mod project: Deathrest Biosculptor Interface.

The interface binds to a Deathrest Casket using native Deathrest binding/capacity, provides vanilla biosculptor routines, and can draw nutrition from a Vanilla Nutrient Paste Expanded PipeSystem network.

See `BUILD_NOTES.md` and `API_AUDIT_1.6.4850.md` for the current implementation notes.
